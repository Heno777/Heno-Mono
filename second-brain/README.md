# Second Brain

Plain-markdown second brain, organised with [PARA](https://fortelabs.com/blog/para/) and maintained by Claude. Separate from the legacy website at the repo root.

| Want to | Do |
|---|---|
| Save something | `/capture <anything>` in Claude Code (works from the phone app) |
| File what you saved | `/process-inbox` |
| Weekly reset | `/weekly-review` |
| Recall something | Just ask — Claude searches the notes and cites them |
| Browse or write by hand | Open this folder as a vault in [Obsidian](https://obsidian.md) |

Start at [Home](Home.md). Conventions Claude follows: [CLAUDE.md](CLAUDE.md).
